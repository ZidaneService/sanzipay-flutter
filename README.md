# SANZIPAY Flutter App

Complete Flutter project for the SANZIPAY fintech app (virtual cards + gift cards).

## How to open

### VS Code / Android Studio
1. Clone the repo
2. Open the folder in VS Code or Android Studio
3. Run `flutter pub get`
4. Run the app on an emulator or device

### FlutterFlow
1. Create a new FlutterFlow project
2. Recreate the screens using this code as reference
3. Or import if your plan supports it

## Screens included
- Login
- Home Dashboard
- Card Details
- Gift Cards
- Transactions
- Profile
